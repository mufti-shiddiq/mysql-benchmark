# Code of Conduct

## Our Standards

This project welcomes practical, respectful collaboration.

Examples of behavior that contributes to a healthy project:

- using clear and considerate language
- focusing technical disagreement on the code and tradeoffs
- accepting constructive feedback
- documenting behavior changes for users
- respecting security-sensitive reports

Examples of unacceptable behavior:

- harassment, insults, or personal attacks
- publishing private information without permission
- deliberately disruptive comments or issues
- public disclosure of unresolved security vulnerabilities

## Enforcement

Project maintainers may remove comments, close issues, reject contributions, or block contributors whose behavior is harmful to the project or its users.

Security reports should follow [SECURITY.md](./SECURITY.md).
